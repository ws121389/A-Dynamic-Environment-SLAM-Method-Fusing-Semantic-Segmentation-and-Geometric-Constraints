# SGR-SLAM

This repository provides project information, dataset links, experimental settings, and access instructions for the paper:

"SGR-SLAM: Semantic and Geometric Robust Visual SLAM in Dynamic Environments"

## Overview

SGR-SLAM is a visual SLAM method for dynamic environments that integrates semantic segmentation and robust geometric constraints. The method is built upon ORB-SLAM3 and combines YOLOv8-Seg, GC-RANSAC, multi-cue geometric consistency checking, and CRF-based dynamic feature refinement.

## Datasets

The experiments in the paper were conducted on publicly available datasets:

- TUM RGB-D Dataset: https://cvg.cit.tum.de/data/datasets/rgbd-dataset
- Bonn RGB-D Dynamic Dataset: https://www.ipb.uni-bonn.de/data/rgbd-dynamic-dataset/
